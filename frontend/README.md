# AI-WasteGuard frontend

Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4 client for
the FastAPI backend in `../api/`.

```bash
npm install
cp .env.local.example .env.local   # set NEXT_PUBLIC_API_BASE_URL
npm run dev
```

See the "Web frontend" section of the [repo README](../README.md) for setup,
CORS requirements, verification notes, and known limitations.
